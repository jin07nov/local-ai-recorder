## プロジェクトのゴール

Gemma Translator を Raspberry Pi 向けのリファレンス実装として活用し、
オリジナルの機能をそのままに、会議用の文字起こし・翻訳・議事録機能を追加する。
まず whisper.cpp による長時間音声の文字起こしを完成させる。
その後、ドイツ語の選択肢を増やし、文字起こしを妨げずにドイツ語 → 日本語などをライブ翻訳してフロントエンドに表示する。
要約・決定事項・TODO・担当者・未決事項の生成は、その後の拡張として扱う。

ユーザーの構想では Pi 5、3.5 インチ LCD、USB マイク・スピーカー、Gemma、Moonshine が動作済み。
これはユーザー提示情報として扱い、今回この作業環境で実機検証したものではない。

## 今回のゴール

元の2人用翻訳画面で German を選び、従来のキー操作でドイツ語の録音・日本語などへの翻訳・読み上げを使えるようにする。実装・ローカル検証済み、Pi の E2E 待ち。
既存6言語の Moonshine 経路を維持し、ドイツ語入力だけ whisper.cpp で原文認識する。既存 `/api/stt` の Float32 PCM 入力・text 応答は維持する。
ドイツ語への翻訳も同じ画面で扱い、読み上げは固定依存の対応を確認して接続する。未対応言語の英語への誤フォールバックを防ぐ。
Pi の既存 Whisper モデルを利用する設定と、元の `start.sh --prod` の更新手順・実機 E2E を案内する。
会議の原文表示は `d7b1d29` で `main` / `origin/main` に反映済み。ユーザー報告では動作するが10秒の待ち時間と base の日本語精度が課題。常駐化・短周期の暫定字幕は今回の対象に含めない。

確認結果: 自動テスト41件、元の翻訳・会議 UI のビルド、`start.sh` の Bash 構文が成功。ドイツ語の送信とエラー表示用 API ヘルパーも Node で確認した。
HTTP 検証の認識器・TTS はテスト用に置換しており、実機のドイツ語認識・翻訳・読み上げ品質は [Pi 手順](../docs/translator.md) で確認する。
